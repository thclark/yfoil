## TRCHEK2's Newton, iterate by iterate

For every dumped SETBL call the instrumented reference writes each TRCHEK2 call's interval inputs and every iterate of its Newton just before the convergence test (`trchek2_<k>.dat`). yFoil's `check_transition_traced` runs on the same inputs: the iterate count must be equal, the initial guess within `TOL_SOLVER` and the final transition point within `TOL_PURE`. The calls are the upper-side transition intervals of the eight iterations of the 7° point of the NACA 0012 polar ([known issues §7.9](../xfoils-known-issues/the-issue-register.md)). The Newton's early exit when there is no amplification over the interval (`xblsys.f:390`) is taken only in a run the reference drives non-finite; every call the reference recorded taking it is replayed and must leave by the same exit at the same iterate ([non-finite probes](../branch-coverage/non-finite-probes.md)).
