# Inviscid panel routines

The panel method and the layer that maps its nodes onto boundary-layer stations, compared with the
reference on the tracked case `naca0012_n60_a2_re1e6` (regenerated by `cargo xtask fixtures --case
naca0012_n60_a2_re1e6`).

| Routines | Test | What is compared |
| --- | --- | --- |
| GGCALC (the unit vorticity distributions, through LUDCMP/BAKSUB) and QDCALC (the full (N+NW)×(N+NW) source-influence matrix DIJ) | `tests/subroutine/ggcalc.rs` | from yFoil's own geometry, against the reference's QINVU and DIJ dumps, through the whole VISCAL prologue: GGCALC → QISET → SPECAL's GAM → XYWAKE → QWCALC → QDCALC. DIJ is compared row-scaled: element-wise relative error is meaningless on its near-zero entries, which a 1-ULP geometry perturbation moves by up to 5e-6 relative ([the error metric](../tolerances/index.md#the-error-metric)) |
| XYWAKE (the wake trajectory, by streamline tracing with PSILIN), SETEXP and QWCALC | `tests/subroutine/xywake.rs` | the wake nodes and wake QINVU, from XFOIL's own aerofoil arrays at the first VISCAL call, so the wake code is tested in isolation; everything passes through `log`, `atan2`, `sqrt` and SETEXP's 100-iteration Newton, at `TOL_PURE` |
| The station pointers (STFIND, IBLPAN, XICALC, IBLSYS) and the inviscid velocity layer (QISET, UICALC) | `tests/subroutine/pointers.rs` | against `xfoil_pointers.dat` and `xfoil_uinv.dat`: integer pointers exactly equal, pure-arithmetic reals bit-identical, quantities through `cos`/`sin` or yFoil's spline derivatives at `TOL_PURE` |

The same prologue is also run end to end from yFoil's own panels, as execution tests
(`tests/execution/prologue_dij.rs`, `prologue_pointers.rs`): [execution
equivalence](../execution-equivalence/index.md).

SETEXP's Newton tolerance of 1e-5 is load-bearing: changing it moves every wake node, so it is
ported character for character ([known issues §7.1](../xfoils-known-issues/the-issue-register.md)).
