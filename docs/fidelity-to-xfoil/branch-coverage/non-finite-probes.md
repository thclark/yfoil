Some branches of the analysis path are reached only on runs whose reference prints a non-finite value: a station Newton with a NaN residual, a fallback taken because a test on NaN is false. Such a run cannot be compared as a whole — the reference cannot reproduce itself on it, and NaN comparisons and `MIN`/`MAX` are where two correct codes legitimately differ — so it is not a candidate for [the minimal case set](the-minimal-case-set.md). Each branch only these runs take is tested instead as an event, replayed from XFOIL's state at that call (`tests/execution/events.rs`). This page lists the probes, measures how far yFoil follows each run anyway, and names the test that replays each branch.
