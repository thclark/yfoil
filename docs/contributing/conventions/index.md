# Conventions

The agreed rules for writing yFoil's code, documentation and history. Each page is the single
statement of its convention; code comments and other pages point here rather than restate it.

| Page | Covers |
| --- | --- |

| [Terminology](terminology.md) | The defined meanings of *deterministic*, *tested*, *ill-conditioned*, *divergent comparison*, *twin*, *noise floor* and *cover* |
| [Figures](figures.md) | How every figure is built as an ironlab figure from computed numbers, and embedded |
| [Branches, commits and versions](branches-commits-and-versions.md) | Branch naming, commit message form, and how the version is bumped |
| [Pull requests](pull-requests.md) | What a pull request must contain, and who merges it |
| [Issues and labels](issues-and-labels.md) | How issues are labelled, and when labels change |

[Fidelity to XFOIL](../../fidelity-to-xfoil/index.md) and
[whether to trust a result](../../using-yfoil/whether-to-trust-a-result.md) link to its
