# Regenerating the reports

Reports are generated, never hand-fed. Every number on a generated page is derived, when the page
is written, from a fixture directory (`tests/fixtures/xfoil/<case>/`, or `target/fixtures/<case>/`
for the untracked study cases) or from `tests/fixtures/subroutines/`. No XFOIL dump, `.dat`,
`.pol`, `DUMP`/`CPWR` output or other reference data is ever committed under `docs/`
(`.gitignore` enforces it), and a report that cannot be regenerated from tracked inputs plus
`cargo xtask fixtures` is not evidence. `docs/` holds only Markdown, ironlab figures (`.fig`) and
the branch-coverage study's two SVGs.

The studies (`geometry-validation`, `series-cases`, `known-issues`, `branch-coverage`) each write
a dated run folder under `scripts/<study>/runs/` (gitignored), with every number in `summary.json`
and a `README.tex` for the paper; `--docs` writes the tracked page from it. The series-cases,
known-issues, branch-coverage and geometry studies take `--render <run folder> --docs`, which
rewrites the pages from an existing run without rerunning anything.

## How the report figures are drawn

Figures are ironlab figures built in Rust by each study from the numbers it computes, through
`src/output/figures.rs` ([figures](conventions/figures.md)). The exception is the branch-coverage
study's branch map and case matrix, still drawn by matplotlib (`scripts/branch-coverage/plot.py`
through `scripts/figures/render.sh`, which needs [`uv`](https://docs.astral.sh/uv/) installed)
until ironlab has an occupancy-matrix figure type.
