# Geometry Validation

This document validates YFoil's geometry generation against XFOIL reference data.

## Methodology

The validation compares panel coordinates generated by YFoil's implementation of XFOIL's
PANE algorithm against coordinates generated directly by XFOIL. Both use the same
algorithm parameters:

- Panel bunching parameter: 1.0
- TE/LE panel density ratio: 0.15
- Refined area/LE panel density ratio: 0.2

## NACA0012 (81 panels)

### Generation Commands

**XFOIL script:**
```
PLOP
G F

NACA 0012
PANE
PPAR
N 81


PSAVE naca0012-81.dat

QUIT
```

**YFoil command (equivalent):**
```
yfoil geom naca 0012 --paneler xfoil -n 81 -o naca0012-81.json
```

## Regeneration

To regenerate this validation after code changes:

```bash
cargo run --bin generate_validation --features plotting
```

This will:
1. Regenerate YFoil geometry for all test cases
2. Recompute comparison metrics against XFOIL baseline
3. Regenerate comparison SVG plots
4. Update this markdown report

**Note:** XFOIL reference data is NOT regenerated (it's the committed baseline).
