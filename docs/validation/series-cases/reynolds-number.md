# Reynolds number

The baselines from Re 1e4 to Re 1e8. At Re 1e4 the boundary layer separates laminar everywhere, so the run uses XFOIL's modified envelope method (`DAMP`); at Re 3e6 the first march at high incidence stalls and takes MRCHUE's iterate fallback.
